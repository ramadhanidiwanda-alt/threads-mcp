# Security Policy

## Reporting a Vulnerability

Jika kamu menemukan celah keamanan di threads-mcp, jangan buka issue publik.

Kirim laporan ke: **security@cuaninsight.com** (atau ganti sesuai kontak kamu)

Kami akan merespon dalam 48 jam dan merilis patch sesegera mungkin.

## Scope

- Access token exposure
- API credential leakage
- Injection vulnerabilities
- Sensitive data leakage via tool output
